# Dream Channel Autopost Bot — эзотерический стиль

Автопостинг в Telegram-канал о толковании снов с помощью ИИ (OpenAI) в **эзотерическом стиле (В)**.

## Особенности

- 3 поста в день: утро, день, вечер
- Каждый пост = текст в мистическом / символическом стиле + картинка от ИИ
- Время публикаций **рандомизируется** в диапазонах:
  - понедельник–воскресенье:
    - утро: 08:00–09:00
    - день: 12:00–14:00
    - вечер: 18:00–19:00
- Тема дня недели учитывается в тексте:
  - Понедельник — эмоции во снах
  - Вторник — природные символы (вода, лес, животные)
  - Среда — архетипы (дом, коридоры, комнаты, двери)
  - Четверг — знаки и предчувствия
  - Пятница — повторяющиеся / навязчивые сны
  - Суббота — подсознание и энергия сна
  - Воскресенье — спокойствие, восстановление, медитативные образы
- В конце каждого поста — аккуратный футер с приглашением написать боту `@whatdreams_bot`
- Логирование постов в `posts_log.json`

## Переменные окружения

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHANNEL_ID`
- `OPENAI_API_KEY`
- `OPENAI_MODEL_CHAT` (например, `gpt-4o-mini`)
- `OPENAI_MODEL_IMAGE` (например, `gpt-image-1`)
